      Works with Amber, Amber Express, ConEd, Localvolts — any retailer that publishes a price sensor.
    

  


  

  

  
  

    Battery dispatch
    

  

  

    
    

      On startup the bridge checks for a scheduled dispatch it left in-flight and applies this
      policy. Notify (the default) is safest — it only alerts your notification
      devices and never commands the battery on boot. Release and
      Resume let the bridge act autonomously: Release clears a force whose
      window has passed; Resume re-forces for whatever time is left in the window. Interruptions
      are always logged (Schedule → activity log, battery-dispatch filter).
    

  


  

  

  
  

    

      
FranklinWH Cloud API

      
    


    

      Enables reserve SoC, TOU schedules and force charge/discharge. The local protocol
      accepts those writes and silently discards them, so they can only run through the
      cloud. Stored on the bridge's data volume; the password is never returned by the API.
