FranklinWH Direct Connect Bridge

Install it your way

Three routes. Run it from the command line on a spare Windows, Mac or Linux computer, set up Home Assistant OS on a spare machine, or add it as an App to the Home Assistant you already have.

Your aGateGive it a fixed address: a DHCP reservation on your router. Note the address; every route asks for it.

A

Spare desktop, from the command line

About 10 minutes. Good for trying it out, or for running it on a computer that stays on.

1 · Get Python 3.11 or newer

Windows 11

Runs inside Ubuntu, using WSL
  1. Right-click Start → Terminal (Admin) and run:
    wsl --install
  2. Restart. Ubuntu opens; choose a username and password.
  3. In the Ubuntu window:
    sudo apt update
sudo apt install -y python3-venv
Then follow the shared steps in the Ubuntu window

macOS

Python from Homebrew
  1. Open Terminal and install Homebrew (from brew.sh):
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Run the two commands it prints under Next steps.
  3. Install Python:
    brew install python
  4. Close Terminal, open a new one, and check:
    python3 --version
    Still 3.9? That is the Mac's built-in Python. Use $(brew --prefix)/bin/python3 in shared step 2.
Or use the installer from python.org

Linux

Ubuntu 24.04 or Debian 13 and newer
  1. Open a terminal and run:
    sudo apt update
sudo apt install -y python3-venv
  2. Check the version is 3.11 or newer:
    python3 --version
Other distributions: install Python 3.11+ and its venv module
2 · Install and run (the same on all three)
1

Make a folder

mkdir fwh-bridge
cd fwh-bridge
2

Create a Python environment

python3 -m venv .venv
source .venv/bin/activate
python --version
Must say 3.11 or newer. Says 3.9 on a Mac? See the macOS column.
3

Install the Bridge

pip install "franklinwh-direct-connect-bridge[cloud] @ https://github.com/david2069/franklinwh-direct-connect-bridge/archive/refs/heads/main.zip"

Straight from GitHub; no git needed.

4

Check it can see your aGate

franklinwh-direct-connect-bridge ping <aGate address>

Each line should say ok.

5

Start it

FWH_HOST=<aGate address> franklinwh-direct-connect-bridge run
The first start prints an admin password, once. Copy it.
6

Open it in a browser

http://localhost:8101

Accept the certificate warning (the Bridge makes its own), then sign in as admin.

Next time 
cd fwh-bridge && source .venv/bin/activate && FWH_HOST=<aGate address> franklinwh-direct-connect-bridge run
Keep the computer awake: history and schedules only run while the Bridge runs.
B

New Home Assistant OS

A spare PC or Raspberry Pi, or a virtual machine on your desktop.

  1. Pick your install

    On home-assistant.io/installation, choose your hardware: a PC (Generic x86-64), a Raspberry Pi, or a virtual machine on Windows, macOS or Linux.

    VM on WindowsVM on macOSVM on Linux

  2. Write the image and boot

    Follow that page's steps for your hardware: write the image to the drive or create the VM, then start it.

  3. Open Home Assistant

    From a browser on the same network, open http://homeassistant.local:8123 and finish onboarding.

  4. Continue with route C

    Your new Home Assistant is ready for the Bridge App.

→
C

Existing Home Assistant OS

Add the Bridge as an App (add-on). About 5 minutes.

  1. Back up first

    Settings → System → Backups → Back up now.

  2. Add the repository

    Press the button, or go to Settings → Apps → App store → ⋮ → Repositories and add https://github.com/david2069/franklinwh-direct-connect-bridge.

    Add repository to my Home Assistant

  3. Install the App

    Find FranklinWH Direct Connect Bridge in the store and press Install.

  4. Tell it where your aGate is

    On Configuration, set fwh_host to the aGate's address. Leave mqtt_enabled on to get Home Assistant entities. Save.

  5. Start and open it

    Start, then open Direct Connect from the sidebar. No password needed there.

  6. Optional: entities in Home Assistant

    Install the Mosquitto broker App. The Bridge finds it on its own, even if you add it later.
